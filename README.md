# 📚 Library Management System

A management application designed to handle book cataloging, user memberships, and lending operations, developed collaboratively as a capstone project.

---

## 🎯 Key Features

- **Catalog Management:** Add, update, remove, and search books by title, author, genre, or ISBN.
- **Member Directory:** Register and manage user profiles and library cards.
- **Circulation & Loans:** Track active book loans, due dates, and returns.
- **Inventory Tracking:** Monitor stock availability and status in real time.
